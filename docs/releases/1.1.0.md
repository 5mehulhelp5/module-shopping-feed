# Mage-OS Shopping Feed 1.1.0

Version 1.1.0 adds optional Nebula Admin support and corrects upload persistence, interrupted generation, Google feed output, and custom CSV serialization. The standard Admin remains available without Nebula. Existing feed configuration is preserved, with required upgrade checks described below.

## Admin and operations

* Nebula installations use a native feed grid with filtering, sorting, pagination, exports, and ACL-controlled actions. The existing standard Admin editor, product preview, and logs remain available. Installing this module does not require Nebula.
* Standard-grid keyword search uses a new feed-name full-text index. Category-map and promotion controls load with their required JavaScript dependencies.
* Upload passwords retain ciphertext on masked saves and avoid double encryption on repeated saves. A `text` column prevents encryption overhead from exceeding the former 255-byte limit. Unreadable credentials must be replaced.
* Upload and schedule changes are scoped to the current feed. Interrupted queue entries can run again on the same day; lock rechecks prevent duplicate work and interrupted output restarts from the beginning.
* Multiple included promotion rules remain separate IDs. Column limits count UTF-8 characters. Microdata requires an explicitly selected feed, URL option values use literal comparisons, and previews escape product data without translating it or exposing exception traces.

## Google and custom feeds

* `identifier_exists=FALSE` requires explicit confirmation that identifiers were not assigned, with no supplied brand, GTIN, or MPN. Missing catalog data alone leaves the field unspecified.
* New Google Shopping feeds contain 31 default columns, including empty MPN/GTIN attribute mappings and an `availability_date` placeholder. SKU is no longer assumed to be a manufacturer MPN. Saved column maps are not rewritten.
* Backorder and preorder rows need a valid future availability date within one year. Missing or invalid dates cause an explained skip. Magento datetime values are normalized to ISO 8601; invalid optional dates are omitted without skipping the product.
* Local Inventory availability follows local quantity and source status instead of online backorder flags. Configurable and grouped parent rows retain their associated-product quantity calculation.
* Generic comma output quotes headers and cells, doubles embedded quotes, and preserves commas, Unicode, and trailing empty fields. Custom names, ordering, values, and non-Google availability remain intact. Tab and other custom delimiters keep their existing cleaning behavior.

See the [complete changelog](../../CHANGELOG.md) and [operating guides](../wiki/Home.md) for configuration details.

## Install or upgrade

```bash
composer require 'mage-os/module-shopping-feed:^1.1'
bin/magento module:enable MageOS_ShoppingFeed
bin/magento setup:upgrade
bin/magento cache:clean
```

For existing installations, back up the database, code, Composer lock file, and feed configuration. Keep schedules and uploads disabled until the new output has been checked. Complete DI compilation and static-content deployment where required by the store's deployment process.

`setup:upgrade` is required for the encrypted-password column and feed-name index. Review older SKU-to-MPN mappings, map real identifiers, and add `availability_date` to existing Google feeds that can emit backorders or preorders. Confirm that custom CSV recipients accept quoted fields before resuming uploads. No Rocket Web package data is migrated automatically. Follow the [1.1 upgrade checklist](../wiki/Installation-and-Upgrade.md#upgrading-from-10-to-11).

## Verification and limits

The final Google/custom-feed run on a disposable Mage-OS 3.5.0 installation without Nebula passed 413 unit tests with 955 assertions, 10 application integration tests with 26 assertions, 14 JavaScript tests, and 33 generated-feed checks. Browser checks covered saving and reopening Google and Generic feeds, previewing products, and downloading a custom CSV that passed strict parsing. The [acceptance report](../reviews/2026-09-28-google-custom-feed-fixes.md) records the exact scope.

Separate runs covered [Nebula and standard Admin compatibility](../reviews/2026-09-25-admin-compatibility.md), [fresh installation with no Nebula packages](../reviews/2026-09-28-without-nebula-acceptance.md), and [Mage-OS 3.5 storefront behavior](../reviews/2026-09-25-mageos-3.5-acceptance.md). The [review-fix record](../reviews/2026-09-24-review-fixes.md) distinguishes reproduced defects from findings that were not reproduced. These dated records describe separate tested candidates, not one combined run.

CI covers PHP syntax on 8.1 through 8.5, frontend checks, and installation, unit tests, integration tests, coding standards, and DI compilation on the configured Magento Open Source and Mage-OS 3.4.0 matrices. Consult the [CI history](https://github.com/mage-os-lab/module-shopping-feed/actions/workflows/ci.yml) for the exact release commit. Mage-OS 3.5.0 remains a local acceptance profile. The test fixtures also support PHPUnit 9, 10, and 12 without changing runtime code.

Local verification does not establish Merchant Center approval or a live recipient transfer. Feed files remain public under the configured media path. Google Ads event delivery on Hyva still requires a separate integration, and independent workers need the shared filesystem lock described in the queue guide.

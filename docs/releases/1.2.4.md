# Mage-OS Shopping Feed 1.2.4

Release date: 2026-10-20.

Version 1.2.4 hardens upload credentials, SFTP server verification, log rotation, and feed-preview permissions. It also fixes inventory and shipping edge cases and completes the Mage-OS module standards work.

## Upgrade requirements

**Existing SFTP destinations require a trusted server host-key fingerprint.** Run `setup:upgrade` to add the fingerprint column, then enter each destination's `SHA256:...` fingerprint in the feed editor. Confirm it with the recipient's server administrator through a trusted channel. A missing or mismatched fingerprint prevents authentication and delivery.

Back up the matching code, database, Composer lock file, and accepted feed files. Upgrade on staging, review upload destinations, and verify a complete generated file and delivery before resuming scheduled transfers.

```sh
composer require 'mage-os/module-shopping-feed:^1.2.4' --no-update
composer update mage-os/module-shopping-feed --with-dependencies
bin/magento setup:upgrade
bin/magento cache:clean
```

Follow the store's normal production compilation and static-content deployment process. The package declares `magento/framework:^103.0.6-p15`, PHP 8.1 through 8.5 subject to platform support, and an explicit `phpseclib/phpseclib:^3.0` dependency. The declared Magento 2.4.6 floor has dependency and syntax checks, not runtime acceptance.

FTP remains available as **FTP (unencrypted)** and sends credentials and data without encryption. The optional Rocket Web migration companion remains separately installed; this upgrade does not import legacy feed records.

## Security and reliability

- Verify the SFTP host key before sending credentials. Reject unknown transfer modes rather than falling back to FTP, and close connections after use.
- Keep upload passwords encrypted in model and form data. Decrypt only when connecting, preserve ciphertext during cloning, and roll back a failed clone.
- Verify a complete gzip log archive before truncating the active log. Preserve the original log if archiving fails.
- Require feed-generation permission for Test Feed and its current and retained legacy editor buttons.
- Render Luma selection scripts through Magento's secure renderer for strict Content Security Policy support.

## Corrections and standards

- Use the MSI source-item interface, handle a missing configurable minimum-price product list, and respect database table prefixes in complex-parent lookups.
- Fall back to UTC for promotion dates without a configured timezone, import the missing tax configuration class, and substitute the actual store name in the microdata message.
- Complete Admin translations and coding-standard cleanup. Add pinned tooling, PHPStan level 8 with a baseline that can only shrink, locked dependency audits, and Mage-OS 3.6 CI coverage.
- Credit [Rocket Web](https://rocketweb.com/) under OSL-3.0, retain original copyright attribution, and clarify source licensing notices.

# Mage-OS Shopping Feed 1.2.2

Release date: 2026-10-05.

## Description cleanup

This patch fixes [#14](https://github.com/mage-os-lab/module-shopping-feed/issues/14): stray quotes in catalog HTML no longer leave image tags in feed descriptions or consume the heading that follows. Inch marks, doubled quotes after media directives, escaped markup, and both quote characters have regression coverage. Literal comparisons and quoted comparison attributes are preserved, and column limits apply after cleanup.

The release includes the required-option pricing, inherited/configurable backorder, and Page Builder fixes from [1.2.1](1.2.1.md). Those are carried-forward fixes, not additional changes introduced in 1.2.2.

## Migrating from Rocket Shopping Feeds

Use the separately installed [Rocket Web migration companion](https://github.com/rocketweb/module-shopping-feed-migration-rocketweb) to move reviewed legacy feed configuration into Mage-OS Shopping Feed. Its stable 1.0.0 release is available on [Packagist](https://packagist.org/packages/rocketweb/module-shopping-feed-migration-rocketweb). Stores without legacy feeds only need the main module.

On staging, after taking the backups described in the [migration guide](../wiki/Rocket-Web-Migration.md), install both packages:

```sh
composer require 'mage-os/module-shopping-feed:^1.2.2' \
  'rocketweb/module-shopping-feed-migration-rocketweb:^1.0' --no-update
composer update mage-os/module-shopping-feed \
  rocketweb/module-shopping-feed-migration-rocketweb --with-dependencies
bin/magento module:enable MageOS_ShoppingFeed RocketWeb_ShoppingFeedMigration
bin/magento setup:upgrade
```

Keep the legacy modules installed and enabled through schema upgrades. Installing the packages runs no migration. Preview each feed and explicitly import it into a disabled destination. Compare generated output before separately reviewed activation; schedules and uploads remain held until then. Custom PHP, shared settings, external schedulers, and recipient URLs need manual review. Automatic rollback is limited to unchanged inactive imports.

Follow the [complete companion instructions](https://github.com/rocketweb/module-shopping-feed-migration-rocketweb#installation) and [migration guide](../wiki/Rocket-Web-Migration.md). Source and destination must share a Magento installation and encryption key. Other legacy versions and store customizations need staging validation.

## Upgrade and verification

There is no schema change or new required dependency relative to 1.2.1. Use the normal Composer/Magento deployment process and regenerate comparison feeds on staging. The editor customization review from 1.2.0 still applies when upgrading from 1.1 or earlier.

Seventeen new data-provider cases cover the description correction; nine fail against the earlier runtime and pass with the fix. The local core suite passes 863 tests on Mage-OS 3.5/PHPUnit 12, Magento 2.4.8/PHPUnit 10, and Magento 2.4.7-p10/PHPUnit 9. All 47 JavaScript checks pass. The merged runtime passed all 25 [post-merge CI jobs](https://github.com/mage-os-lab/module-shopping-feed/actions/runs/37332361658).

The [release preparation record](../reviews/2026-10-05-release-1.2.2-preparation.md) identifies the branch/worktree audit, exact runtime, package sources, local checks, and publication gates. Existing-store migration, full browser/operational acceptance, and external recipient cutover remain within their recorded scopes and require target-store verification.

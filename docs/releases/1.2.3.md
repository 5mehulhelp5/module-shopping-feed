# Mage-OS Shopping Feed 1.2.3

Release date: 2026-10-13.

## Inventory and generation

Website-stock reservations are applied once to the combined quantity of enabled physical sources. Fractional quantities and reservations are preserved, disabled sources are excluded, and each feed resolves its own website stock. Local Inventory rows report physical-source quantity without assigning website reservations to individual stores. Compare changed quantities against the [Local Inventory guide](../wiki/Google-Local-Inventory-and-MSI.md) before resuming delivery.

Manual feeds with no schedules can checkpoint and resume when generation switches automatically to batch mode. Feed construction initializes configuration correctly; status/message updates restore later configuration and timestamp saves. Skipped product IDs are retained, unknown inheritance modes fail clearly, and unfinished markup fragments are removed from descriptions.

## Promotions, Admin, and storefront

- Create and update promotion settings through the feed configuration model, honor excluded rules, buffer cache writes per generation batch, and normalize promotion titles for TSV output.
- Preserve active Nebula column filters through paging and sorting, retain explicit filter clearing, and hide actions without an ACL resource. Malformed Generate/View Log identities return a recoverable validation message.
- Display the installed Composer package version in Admin's **Versions installed** field, with the existing schema-version fallback for source installations and related modules ([#17](https://github.com/mage-os-lab/module-shopping-feed/issues/17)).
- Preserve native title/SKU microdata when no replacement feed is selected, encode configurable JSON safely in inline scripts, and apply URL selections after Magento initializes dropdowns or swatches.

## Upgrade

There is no database schema change or new required Composer dependency relative to 1.2.2. Use the [upgrade checklist](../wiki/Installation-and-Upgrade.md#upgrading-from-122-to-123), back up the matching code/database/lock/output, and follow the store's normal deployment process. Review inventory, promotions, manual batching, and storefront output on staging before enabling schedules or uploads.

```sh
composer require 'mage-os/module-shopping-feed:^1.2.3' --no-update
composer update mage-os/module-shopping-feed --with-dependencies
bin/magento setup:upgrade
bin/magento cache:clean
```

The [Rocket Web migration companion](https://github.com/rocketweb/module-shopping-feed-migration-rocketweb) remains optional and separately installed. Upgrading this package does not import legacy data or activate destination feeds.

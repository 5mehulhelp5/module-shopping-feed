## Defects and regression evidence

- Issue #9: zero is a valid minimum, explicit defaults are evaluated separately, and Magento's percentage calculator receives a copied option/value with the child's price context. Original parent option/value references remain unchanged. Optional add-ons are not included.
- Issue #10: native stock getters resolve inherited backorder configuration; configurable children aggregate in stock, backorder, preorder, then out of stock. Explicitly out-of-stock parents remain so. Positive MSI source quantity takes priority over later backordered sources. Local Inventory quantity rules remain unchanged.
- Issue #11 and its follow-up: clean raw/escaped markup and style/script content around two entity-decoding passes, normalize decoded separators, then apply text limits. Regression cases retain literal comparisons, quoted attributes, UTF-8 limits, and enclosed/custom delimiter behavior.

All 32 new cases were run against the exact v1.2.0 runtime: **22 assertion failures**. With the candidate fixes, all **32 tests / 35 assertions** pass. This includes a native Magento percentage-calculator check using different parent/child prices. Separate mock-only conversion coverage would have missed that context error.

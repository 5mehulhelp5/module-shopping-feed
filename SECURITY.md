# Security policy

## Supported versions

Security fixes are provided for the latest stable tagged release, starting with 1.0.0. Install the latest available patch release in that line.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability.

Email **security@mage-os.org** with the module name (`mage-os/module-shopping-feed`), the affected version or commit, reproduction steps, expected impact, and any suggested mitigation. Reports to that address reach the Mage-OS security contacts even when a maintainer is unavailable.

When GitHub's [private vulnerability reporting](https://github.com/mage-os-lab/module-shopping-feed/security/advisories/new) is enabled for this repository, you can use it as a second route.

We will acknowledge a complete report as soon as maintainers are available and will keep the reporter informed while the issue is assessed. Once a fix is released, the advisory is published and the reporter is credited unless they prefer otherwise.
